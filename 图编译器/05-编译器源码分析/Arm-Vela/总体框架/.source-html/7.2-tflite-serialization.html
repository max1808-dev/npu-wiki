This document details how the Ethos-U Vela compiler serializes and deserializes TensorFlow Lite (TFLite) model data. It covers the process of reading TFLite models into the internal representation, and writing optimized models back to TFLite format, including memory allocation information needed for efficient execution on Ethos-U NPUs.

Overview

TFLite serialization is a critical component of the Vela compilation pipeline, forming the interface between the external model format and the internal compiler representation. It consists of two main parts:

  1. TFLite Reader - Parses TFLite flatbuffer files into internal neural network graph representation
  2. TFLite Writer - Serializes optimized neural network graphs back to TFLite format

Sources: ethosu/vela/tflite_reader.py30-368 ethosu/vela/tflite_writer.py70-550

TFLite Model Structure

The TensorFlow Lite format uses FlatBuffers, a binary serialization format that allows efficient memory access without parsing overhead. Understanding this structure is crucial for both reading and writing operations.

Key Components

TFLiteGraph

Main class that handles reading and parsing a TFLite model file. It manages the entire process from loading the buffer to constructing the neural network graph.

TFLiteSubgraph

Represents a subgraph in the TFLite model. Responsible for parsing tensors and operations within a subgraph and connecting them correctly.

Parser Methods

The reader includes specialized methods for parsing different components:

  • parse_buffer - Extracts raw data from buffers
  • parse_tensor - Creates Tensor objects with shapes, types, and quantization info
  • parse_operator - Creates Operation objects and connects them to tensors
  • parse_operator_code - Maps TFLite operator codes to internal operation types

Buffer Handling

Special attention is given to buffer management since they contain the actual data for tensors:

  • Buffer 0 is always empty and used for intermediate tensors
  • Constant tensors (weights) are assigned unique buffers
  • Compressed weight values are properly serialized

    tflite_graph = TFLiteGraph(filename, batch_size, feed_dict, output_node_names, initialisation_nodes)

def write_tflite(nng, filename):
    writer = TFLiteSerialiser(nng)
    buf = writer.serialise()
 
    with open(filename, "wb") as f:
        f.write(buf)
        
def write_tflite_buffer(nng):
    writer = TFLiteSerialiser(nng)
    buf = writer.serialise()
    return buf

Summary

TFLite serialization in the Ethos-U Vela compiler is responsible for:

  1. Reading TFLite model files and converting them to the internal neural network graph representation
  2. Writing optimized neural network graphs back to TFLite format
  3. Including memory allocation information to optimize runtime performance on Ethos-U NPUs
  4. Preserving tensor properties including shapes, data types, and quantization parameters

The serialization process handles all standard TFLite components like operations, tensors, and buffers, as well as Ethos-U specific optimizations and metadata.
