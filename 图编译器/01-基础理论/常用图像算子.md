# 常用图像算子

| 算子 | 数学语义 | 硬件关注 |
|---|---|---|
| Conv2D | 每个 filter 对输入通道及空间窗口求加权和 | MAC、权重、累加 |
| DepthwiseConv2D | 每个输入通道独立卷积，可有 channel multiplier | 通道映射 |
| MaxPool | 每个通道独立取窗口最大值 | 比较与边界 |
| Add/Mul | 逐元素运算，可能广播 | 广播、量化 |
| ReLU | max(0,x) | clamp |
| Logistic | 1/(1+exp(-x)) | LUT或近似 |
| Resize | 空间重采样 | 插值和坐标规则 |
| Concat | 沿指定轴连接 | 布局与搬运 |
