# 八维评价体系

| 维度 | 采集字段 | 验证方法 |
|---|---|---|
| 基本信息 | 版本、license、源码开放范围 | 仓库与许可证 |
| 模型兼容 | 输入格式、opset、shape限制 | 官方支持矩阵和最小模型 |
| 硬件 | 目标、存储、数据类型 | target 文档 |
| 架构 | IR、pass、后端接口 | 源码 |
| 优化 | fusion、tiling、layout、调度 | 编译前后 dump |
| 算子量化 | 参数约束、精度与回退 | 算子规范、边界测试 |
| 部署 | OS、runtime、driver、内存 | 真机运行 |
| 二次开发 | 新算子、后端扩展、许可 | 原型验证 |

禁止把“有公开 SDK”直接等同于编译器源码开放。未核实字段标记未核实，不等于不支持。跨硬件性能比较必须统一模型、精度、输入、时钟和测量范围。
