# 技术路线与产品对比

> 资料基线：2026-11-26；不是市场份额排名。支持能力必须绑定具体版本和目标。

| 项目 | 技术定位 | 目标 | 输出或部署方式 | 官方资料 |
|---|---|---|---|---|
| Arm Vela | 专用 AOT 编译器 | Ethos-U55/U65/U85 | TFLite custom op 或目标命令流 | [Arm](https://arm-software.github.io/CMSIS-Ethos-U/main/vela/index.html) |
| Apache TVM | 通用 ML 编译器 | 多种 CPU/GPU 等后端 | 目标代码及 runtime | [TVM](https://tvm.apache.org/docs/arch/) |
| OpenXLA XLA | 机器学习编译器 | CPU/GPU 等目标 | 目标可执行程序 | [XLA](https://openxla.org/xla/architecture) |
| IREE | 编译器与运行时 | CPU/GPU及嵌入式配置 | 编译模块及部署接口 | [IREE](https://iree.dev/guides/deployment-configurations/) |
| NVIDIA TensorRT | 推理优化 SDK | NVIDIA GPU；特定平台 DLA | 推理 engine | [TensorRT](https://docs.nvidia.com/deeplearning/tensorrt/latest/index.html) |
| Rockchip RKNN | 芯片专用部署工具 | Rockchip NPU | RKNN 模型 | [RKNN](https://github.com/airockchip/rknn-toolkit2) |
| AMD Vitis AI | DPU 编译部署工具链 | AMD DPU | 编译模型 | [UG1414](https://docs.amd.com/r/en-US/ug1414-vitis-ai/Vitis-AI-Compiler) |
| Hailo DFC | Dataflow 编译工具 | Hailo 加速器 | 具体格式待按版本核实 | [厂商社区](https://community.hailo.ai/t/dataflow-compiler-best-practice/62) |

MLIR 是构建编译器的基础设施，不应和完整推理产品直接排名。当前优先分析 Vela；TVM 与 IREE 可作为可扩展架构的后续候选。
