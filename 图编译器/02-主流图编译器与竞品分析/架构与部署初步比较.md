# 架构与部署初步比较

| 项目 | 已知架构特征 | 对自研 NPU 的研究价值 | 未完成验证 |
|---|---|---|---|
| Vela | 目标专用编译、内存规划、命令流 | 小型 SRAM NPU 后端 | 固定 commit 的调用链 |
| TVM | Relax / TensorIR | 多层 IR、跨层优化 | 自定义后端移植成本 |
| XLA | HLO 优化与目标后端 | 高层优化及 lowering | MCU 部署适用性 |
| IREE | 可配置部署与目标 | Runtime 与设备抽象 | NACC 接口原型 |
| TensorRT | GPU 推理 engine | 优化及性能评估方法 | 内部编译源码开放范围 |
| RKNN | 芯片专用模型转换部署 | 产品化工具体验 | 内部 IR 与算法 |
| Vitis AI | 按 DPU 架构编译 | 硬件描述与目标映射 | 具体版本的后端扩展 |
| Hailo DFC | 数据流编译 | 数据流映射思路 | 公开接口及内部实现 |

来源见 [[技术路线与产品对比]]。此表不是完整算子支持矩阵。
