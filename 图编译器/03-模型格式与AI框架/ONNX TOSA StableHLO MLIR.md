# ONNX TOSA StableHLO MLIR

ONNX 是模型交换表示，节点的语义取决于 domain 与 opset。TOSA 是张量算子标准；StableHLO 是面向机器学习的高层操作表示；MLIR 提供 Dialect、类型、Operation 和 Pass 基础设施。不能假定不同表示中的同名算子具有完全相同的 padding 或量化语义。

[ONNX](https://onnx.ai/) · [TOSA](https://www.mlplatform.org/tosa/) · [StableHLO](https://openxla.org/stablehlo) · [MLIR](https://mlir.llvm.org/)
