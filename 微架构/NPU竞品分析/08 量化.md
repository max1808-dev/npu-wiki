## LiteRT INT8规范

| 参数 | Conv2D | DepthwiseConv2D |
| --- | --- | --- |
| IFM | INT8 per-tensor | INT8 per-tensor |
| Weight | INT8 per-axis，轴0 | INT8 per-axis，轴3 |
| Weight Zero Point | 0 | 0 |
| Bias | INT32 | INT32 |
| OFM | INT8 per-tensor | INT8 per-tensor |

MaxPool、AveragePool、Concat、Reshape、Pad、Transpose、Resize Bilinear要求输入输出量化参数一致。Logistic/Softmax输出 scale=1/256、zero point=-128；Tanh输出 scale=1/128、zero point=0。

$r=(q-z)s$。卷积累加后需要 per-channel requantization、舍入及饱和；具体算法需对照 reference kernel。
